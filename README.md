# SOUL TETHER / ソウルテザー

2D横スクロールアクション（実体と霊体を切り替えて進む）。iPhone横持ち優先。

## 2つの出力

| ファイル | 用途 |
|---|---|
| `soul_tether.html` | **1ファイル版**。画像・音・フォントをすべて内蔵。ダブルクリックでオフラインでも遊べる。 |
| `dist/` | **公開用（Web / PWA）版**。素材を別ファイルに分け、2回目以降は端末に保存された分ですぐ起動・オフライン可。iPhoneは「ホーム画面に追加」で全画面アプリになる。曲は元の音質。 |

## ビルド

```bash
python3 tools/build_assets.py soul_tether.html   # assets/src の画像 → 1ファイル版に埋め込み
python3 tools/build_audio.py  soul_tether.html   # assets/src/audio の音 → 1ファイル版に埋め込み
python3 tools/build_web.py                       # 1ファイル版 → dist/（公開用）
```

python3 tools/build_font.py   soul_tether.html   # 文章を変えたら実行：使っている文字だけでフォントを作り直す

必要なもの：Python 3（Pillow, numpy, scipy, fonttools, brotli）、ffmpeg。

※ ビルドの順番は build_assets → build_audio → build_font → build_web。

## フォルダ

- `soul_tether.html` … ゲーム本体（コード＋埋め込み素材）
- `assets/src/` … 素材の原本（ドット絵シート、スチル、背景、UI）
- `assets/src/audio/` … BGM・SE・エンディング曲（Suno）の原本
- `tools/` … 素材の切り出し・埋め込み・Web版作成スクリプト
- `docs/asset_prompts.md` … 素材生成AI用プロンプト集
- `dist/` … 公開用の出力（`build_web.py` が毎回作り直す）

## 公開・テスト

- **iPhoneで手早くテスト（無料）**：PCで `cd dist && python3 -m http.server 8000`、同じWi-Fiの iPhone の Safari で `http://<PCのIPアドレス>:8000` を開く（保存機能は https でのみ有効）。
- **自動で公開URLを更新（無料枠）**：Cloudflare Pages をこのリポジトリに接続し、「ビルドコマンド：なし」「出力ディレクトリ：`dist`」。push するたびに更新される。
- **本番（Netlify）**：Publish directory を `dist` に。`dist/_headers` でキャッシュ設定済み。

## クレジット

- フォント：DotGothic16（SIL Open Font License 1.1, Fontworks Inc.）
- 音楽：Suno（主題歌「魂の糸」、エンディング「届かない朝」「ふたりの朝」、ステージ・ボス曲）
- ドット絵・イラスト：ChatGPT

## v52 の変更点

- **描画**：ゲーム画面を 4 倍解像度（1536×864）で描画。レン・ミオ・敵・エフェクト・足場は元絵から 4 倍で切り出し直し（元絵の解像度が足りないボスなどは従来の 2 倍ドットのまま、にじまないよう整数倍で表示）。重い端末では自動で従来解像度に落ちる（設定「高画質」で固定可）。背景は彩度と明るさを抑えて手前を見やすくし、接地影・キャラの灯り・ビネットを追加。
- **動作**：ゲームの進行を画面のリフレッシュレートから切り離し、常に 60fps 相当で動くように（120Hz 端末で倍速になる問題を解消）。
- **操作**：タッチ操作を作り直し。画面左半分のどこでも出るアナログスティック（霊体は全方向に飛べる）、右は親指の弧に沿った 4 ボタン（押した位置に一番近いボタンが反応、ATTACK⇔JUMP は指を滑らせて切り替え可）。16:9 の外側の余白やノッチ部分も操作に使うので、ボタンがゲーム画面にかぶりにくい。カメラの先読みをなめらかに。キーボード：Esc でポーズ、Enter で開始。
- **テンポ**：文字送り・開始バナー・リトライ・暗転を短縮。移動と攻撃の間隔を少し速く。敵に当てたときの手応え（ヒットフラッシュ・ヒットストップ）を追加。
- **文章**：会話 120 シーンを全面改稿。ヒント・目標・ステージ紹介・記録文・トーストなど指示文 750 か所を、用語を統一して書き直し（実体／霊体／身体／魂の糸）。
- **その他**：設定が再起動で消える不具合、空中で SOULを押すと身体が宙に止まる不具合を修正。NEW GAME でセーブを消す前に確認。
- **実体の移動**：歩行を約3割速く（2.3→2.95）、加速も強く。実体用の DASH ボタンを追加（ダッシュは距離・再使用とも強化）。
- **通れる／通れない**：いまの姿で通り抜けられるものは薄く透ける（霊体のときの扉と足場、実体のときの紫の障壁）。くぐれる薄い足場は、乗っていないあいだ暗くなり上の縁が光る。ぶつかると障害物が光り、初回だけ「どちらの姿なら通れるか」を表示。
- **仕上げ**：敵の頭上の印を小さくし、いまの姿で斬れる印だけ明るく表示。ジャンプ・着地・ダッシュの砂ぼこり、被弾時と体力わずかのときの画面端の赤（霊体は青）。1ファイル版の曲を 96kbps に、スチルとスプライトの圧縮を高品質に戻した（約 76MB）。

## v53 の変更点（ストーリーを楽しむための快適さ）

- **真エンドの解放条件**：ソウルシャード36個の全回収が不要に。12章をクリアすれば、そのまま最終章（EX）へ進める。シャードは魂の糸の長さと ART の特典として残る。
- **遊び方の選択**：NEW GAME の最初に「ストーリー重視／標準」を選ぶ。ストーリー重視は、受けるダメージ半分・しばらく被弾しないと体力が戻る・露見や身体の危険などのゲージが半分の速さ・順番の謎解きを間違えてもやり直しにならない。OPTIONS → ACCESS でいつでも切り替え可。
- **会話**：LOG（読み返し）を追加。一度読んだ会話は SKIP で飛ばせる（この端末で既読を記録）。やられてチェックポイントに戻っても、その挑戦中に見た会話はもう流れない。
- **あらすじ**：CONTINUE で再開すると「これまでのあらすじ」を表示。ポーズ画面の「あらすじ」で、話の流れ・いまの目的・手がかりを確認できる。
- **画面**：ポーズ画面を内容に合わせて伸びるパネルに。キーボード：L＝会話ログ、Tab＝既読の会話を飛ばす。
